# Cuerpos Geométricos Estructurados

Este proyecto es una aplicación de consola desarrollada en **Java** utilizando **Visual Studio Code**. El sistema permite realizar cálculos precisos de áreas y volúmenes para una amplia variedad de sólidos tridimensionales, aplicando conceptos fundamentales de programación estructurada.

## Objetivo
Implementar un sistema robusto que utilice variables, operadores y expresiones matemáticas complejas, junto con estructuras de control y validación de entrada de datos, para resolver problemas geométricos de manera eficiente.

## Funcionalidades
* **Menú Interactivo:** Acceso a 16 cuerpos geométricos distintos a través de una interfaz de consola.
* **Cálculos Integrales:** Determinación del Área Lateral ($A_L$), Área Total ($A_T$) y Volumen ($V$) para cada figura.
* **Validación de Datos:** Control estricto de las entradas del usuario para prevenir errores en las operaciones matemáticas.
* **Persistencia del Programa:** El sistema permite realizar múltiples cálculos de forma consecutiva, regresando al menú principal hasta que el usuario decida finalizar la sesión.
* **Mensaje de Salida:** Cierre formal de la aplicación con un mensaje de despedida tras la confirmación del usuario.

## Sólidos Soportados
La aplicación incluye soporte para los siguientes 16 cuerpos:
1. Prisma
2. Cilindro
3. Pirámide
4. Cono
5. Esfera
6. Zona Esférica
7. Casquete Esférico
8. Huso y Cuña Esférica
9. Ortoedro
10. Tetraedro
11. Hexaedro
12. Octaedro
13. Dodecaedro
14. Icosaedro
15. Tronco de Cono
16. Tronco de Pirámide
